# MANIF' V0.1

Prototype mobile-first d'un assistant pour les manifestations associatives et locales.

## Objectif V0.1

Un organisateur décrit une fête/kermesse et obtient une checklist personnalisée des démarches et points à vérifier.

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Périmètre actuel

- Informations événement
- Espace public / circulation
- Buvette avec alcool
- Musique
- Restauration
- Assurance RC
- Première orientation secours
- Recommandation fortes chaleurs

Les règles critiques doivent rester fondées sur des sources officielles. MANIF' est un outil d'orientation et ne remplace pas les autorités compétentes.
